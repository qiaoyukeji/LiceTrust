# LiceTrust — 正版软件管理平台（多租户版）

> **LiceTrust**：License（软件许可）+ Trust（可信）——强调"许可可信、正版可信"的多租户 SaaS 化企业软件正版化管理信息系统，契合政务与国企的正版化治理定位。
>
> 开源协议：[Apache License 2.0](LICENSE)

**多租户 SaaS 化的企业软件正版化管理信息系统**：企业在线注册账号并创建本公司，自助维护组织架构与公司信息，管理本公司全部计算机及**操作系统、办公软件、杀毒软件、工业软件**四类软件的全生命周期台账，实现"**看得见、管得住、对得上、拿得出、报得快**"的正版化管理目标，并内置**数据备份恢复**与**附件3 格式 Excel 导入导出**（对接《正版软件管理工作指南》报送格式）。

依据《正版软件管理平台_需求分析与设计文档》（V1.0）实现；开发过程采用敏捷方式（Sprint 0-7，记录见 [docs/AGILE.md](docs/AGILE.md)）。

## 三、软件实现方式

### 1. 总体架构与请求处理链

前后端分离：PC/移动端为 Vue SPA，后端 Express 提供 REST API，统一响应 `{code, message, data}`。

```
请求 → CORS → JSON Body 解析 → 审计中间件(响应后留痕)
     → /api/* → authGuard 中间件链：
         ① JWT 校验（Bearer）→ 加载用户/角色/权限
         ② 租户上下文（AsyncLocalStorage）→ ③ RBAC 权限点 → ④ 路由业务处理
     → 统一错误处理（ApiError → {code, message}）
```

### 2. 数据访问层：schema 驱动的代码生成（核心实现）

**业务代码零手写 SQL**。数据层由两个生成器从声明式定义产出：

- `scripts/gen-dao.js`：读取 `schema.js` 的 28 张表定义 → 生成每表 `list / listAll / count / get / insert / update / remove / purgeByTenant` 共 8 类函数（27 个 DAO 模块）
- `scripts/gen-queries.js`：读取 `scripts/query-defs/*.js` 的声明式查询定义（SQL 文本 + 参数构建函数）→ 生成 JOIN 查询模块

**安全模式**（与静态安全扫描规则一致）：
- 所有 SQL 为源码**字面量字符串**，值一律 `?` 占位符参数绑定
- 可选过滤条件采用**静态 NULL-TRICK**：`AND ( ? IS NULL OR col = ? )`，未传参数绑 null 即跳过该条件，避免任何运行时 SQL 拼接
- 表名/列名标识符经白名单校验；SQL 文本不跨函数传递（组装与执行同函数完成）

修改表结构时：改 `schema.js` / `query-defs` → `node scripts/gen-dao.js && node scripts/gen-queries.js` → DAO/查询模块重新生成。

### 3. 多租户隔离实现

- `sys_tenant` 表承载企业；21 张业务表带 `tenant_id` 列（`sys_user` 为例外表，登录需跨租户查询，显式过滤）
- `db/tenantContext.js` 用 **AsyncLocalStorage** 存储请求级租户上下文：`authGuard` 认证后以 `runWithTenant(user.tenant_id, next)` 包装请求链——并发请求互不污染（模块级变量方案有竞态，已弃用）
- 生成器对含 `tenant_id` 的表自动实现三条规则：
  1. **INSERT 自动注入**：未显式指定租户时写入当前上下文租户
  2. **读/删/改强制过滤**：所有 SELECT/COUNT/GET/UPDATE/DELETE 追加 `AND ( ? IS NULL OR tenant_id = ? )`，平台账号（tenant_id=0）上下文为 null 即全量可见
  3. 编号生成器扫描**含已删行**的全量编号取最大序号+1，保证编号永不复用（不与唯一索引冲突）
- 企业注册接口在单事务内完成：建租户 → 顶层组织 → 默认部门 → 总管理员 → 绑定 ADMIN 角色

### 4. 权限体系实现（RBAC 双维度）

- **功能权限**：`sys_role.perms` 存权限点数组（40+，如 `computer:edit`、`entitlement:secret`），`authGuard` 汇总用户角色权限并集，路由用 `requirePerm('xxx:edit')` 校验；前端用 `v-perm` 指令控制按钮/菜单显隐
- **数据权限**：`sys_role.data_scope` 四级（1全部/2本单位/3本部门/4仅本人），路由用 `scopeFilters(user, fields)` 把数据权限翻译为 DAO 过滤条件
- 超级角色持 `*` 通配权限；权限矩阵有 20 项自动化断言（越权必 403）

### 5. 安装维护工作流实现

固定两级审批**状态机**（未引入 Flowable）：`0草稿 → 10待部门审核 → 20待信息化审核 → 30待执行 → 40待使用人确认 → 50已完成 / 60已驳回`。每个动作校验当前状态与权限，审批/确认写 `flow_approval/flow_confirm` 留痕；**确认时在事务内按申请类型写回台账**（安装插入明细、卸载逻辑删除明细、升级更新版本并写双日志），保证"账实相符"。使用人确认需电子签名（文本签名）且校验本人为计算机使用人。

### 6. 安全实现

- 敏感字段（激活码/序列号/管理员密码）入库前 `AES-256-GCM` 加密（密钥独立配置，随机 IV + 认证标签）；接口返回一律脱敏；查看明文走 `reveal` 接口——bcrypt 校验登录密码二次认证 + 审计记录
- 审计中间件对全部写操作在响应结束后异步落库（操作人/模块/路径/参数脱敏/IP/时间），审计表无删除接口
- 业务编号（软件/电脑/单据）由编号服务生成：扫描含已删行的全量编号取最大序号+1 并循环唯一性检查（逻辑删除不占号复用）
- 文件上传：扩展名白名单 + 20MB 限制 + 随机文件名

### 7. 报表与备份实现

- **报表导出**：exceljs 按附件模板排版（标题/盖章行/表头/数据/列宽），流式输出 xlsx；预览接口返回 `{columns, rows, topStats}` 供前端动态渲染
- **附件3 导入**：SheetJS 解析 .xls/.xlsx → 自动定位表头行 → 逐行校验 → 计算机/软件不存在自动建档（编号生成）→ 成功/失败逐行反馈
- **备份恢复**：导出为按依赖序排列的 22 张表 JSON；恢复在单事务内先物理清空本租户数据（生成器产出 `purgeByTenant`），再按依赖顺序**外键映射重建**（旧 ID → 新 ID 映射表重写关联字段，合同内嵌 JSON 中的软件 ID、混合目标 ID 均处理），用户按 username upsert 防止管理员被锁

### 8. 消息通知实现

**通道解析优先级**（`notifyService`）：租户自有配置（`tenant_msg_config`，短信 AccessKey/SMTP 密码 AES 加密存储）→ 平台通道（`platform_msg_config` 已启用且租户被分配额度，已用量 < 配额）→ 均不可用返回 null 降级。发送全部落 `msg_send_log`（通道/来源/接收方/状态）；平台通道发送自动扣减 `sys_tenant` 的 `sms_used/email_used`。

**到期提醒**：授权到期前 N 天（租户可配）按租户配置自动向管理员发送短信/邮件。**PNVS 短信认证**：`Dypnsapi.SendSmsVerifyCode`（占位符 `##code##`，阿里云生成）+ `CheckSmsVerifyCode`（核验以 `Model.VerifyResult === 'PASS'` 为准），与 `Dysmsapi.SendSms` 共用 V3 签名调用器。

### 9. 前端实现

- **PC 端**：Vue Router 登录守卫 + 路由 meta 权限；Pinia 用户 store（token/权限点）；Axios 拦截器统一处理 code!==0/401/403；列表页统一 CrudTable 模式（查询栏+表格+分页）；ECharts 统计与大屏；`/screen` 大屏独立于后台布局，60s 自动刷新
- **移动端**：Vant 组件体系，Tabbar 四页（首页入口/信息查找/信息录入/我的），van-list 无限加载；录入表单用 Picker 弹层选择（人员/单位/部门/类型/日期）
- **扫码**：浏览器 `BarcodeDetector` API 摄像头实时识别 + 扫码枪键盘输入兼容 + 手动输入降级

### 10. 测试与质量实现

- `scripts/smoke.js`：71 项 API 断言（登录/全模块列表/详情/流程闭环/预警/报表导出/RBAC 越权/数据隔离/多租户）
- `scripts/test-suite.js`：53 项深化断言（权限矩阵/状态机非法流转/一致性/SQL 注入与 XSS/脱敏/性能）
- 浏览器自动化 GUI 遍历（27 页无空白无报错）+ 并发竞态专项（8 轮×6 并发租户隔离验证）
- 全部代码经静态安全扫描（SQL 注入/路径穿越/弱加密/命令注入规则）并按"字面量 SQL + 参数绑定 + 白名单"模式合规实现
