## 3. 安全测试结论（对应文档 9.x）

- SQL 注入：`' OR '1'='1`、`; DROP TABLE` 等注入串作为查询值/关键字均被参数化安全处理，数据完好
- 认证：未认证 401、伪造 token 401、会话过期 401
- 越权：横向（员工访问他人确认）403、纵向（员工访问用户管理/授权）403，权限矩阵 20 项全部符合预期
- 敏感信息：列表序列号/激活码/管理员密码均脱敏；明文 reveal 必须登录密码二次认证且连续失败均 403
- XSS：脚本字符串入库不崩溃，前端转义展示（Vue 默认转义）
- 审计：写操作全量留痕且无删除接口（DELETE /audit-logs 404）

## 4. 性能抽查（文档 4.5）

- 批量导入 500 条安装记录：响应 <20s（含逐条校验），导入结果含逐行成功/失败反馈
- 2 万级数据量分页查询（20条/页）：实测 <200ms，满足"常规页面响应≤2秒"

## 5. 数据一致性结论（表表相符/账账相符/账实相符）

- 逐软件比对：软件资产库对账列 install_count（明细实时聚合）= 明细表按名称检索条数，一致
- 升级/卸载流程写回后，明细条数与维护日志同步变化（升级双日志 FR-04-07 验证通过）
- 许可数量 < 安装数量的软件均被超授权预警覆盖
